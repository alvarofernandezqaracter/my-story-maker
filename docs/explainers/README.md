# Explainers

**Hueco: lo rellena T15b.**

Aquí irán explicaciones cortas, en lenguaje llano, de las piezas del sistema que
alguien de fuera necesita entender para seguir la presentación: una por
fichero, cada una contando qué problema resuelve la pieza y cómo, con un ejemplo
sacado de la novela de ejemplo de `ejemplos/`. Se escriben al final porque
enseñan resultados, y esos resultados todavía no existen.

Lo que ya está escrito en otro sitio no se repite aquí, se enlaza: la
ontología en [`definitions.md`](../definitions.md), la arquitectura en
[`architecture.md`](../architecture.md) y el porqué de cada decisión en las
specs (ver [`proceso.md`](../proceso.md)).
